# locomo-salt

A minimal React note-taking and task management app.

## Features

- Add, edit, delete, and complete tasks
- Local task persistence using `localStorage`
- Task categories: Work, Study, Personal, Shopping, Other
- Task completion tracking
- Clear completed tasks
- Responsive UI with React components

## Tech Stack

- React 19
- TypeScript
- Vite
- ESLint

## Getting Started

### Prerequisites

- Node.js >= 18
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

## Usage

1. Click the add button to create a new task.
2. Use the input field to enter a task name.
3. Mark tasks as completed using the checkbox.
4. Edit or delete tasks using the action buttons.
5. Clear all completed tasks with the clear button.
6. Tasks are automatically saved to the browser's `localStorage`.
